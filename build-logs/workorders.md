# Management site upgrade
## Bonan Tower Orders Creations
- Need to have a drop down on Bonan Order -> change button to a drop down showing 'Daily', 'Weekly' and 'Monthly' report options 
- Daily reports will automatically populate the day and time of the order getting created, but can be edited later (incase if Admin or worker is filling in order online after from doing in person)
- Weekly reports will pull and link daily reports into them as well as then have the weekly elements that are unique. Dates will be populated based on the daily report pulling from Sunday->Saturday
- Monthly reports will link the daily and weekly reports in them as well

We are setting up a system so that orders are tracked and then shared between Bonan towers and Taylor Leonard Corp so that information is tracked, logged and connected. For example, if someone at Bonan towers cant find a specific day report they could pull up the weekly or monthly one, and click the day and will take them to it or see an overview. So database association and connections need to be established

In addition to walkthrough reports and summaries of weekly and monthly, attached to those dates will be specific:
- Bonan Work Order (general work order filled out by either Bonan or TL Corp)
- Bonan Towers Incident Alarm Report 
Those reports will be associated to daily, weekly and monthly reports based on the date they were filed

Everything will be organized by the date of each report and such

The Daily reports are essentially walk throughs, when clicking on it from the work order management page it will essentially pull up a new page which is like a check list 

When filling out these reports they will be saved periodically as drafts to the cloud whenever done editing or filling out after 30 seconds until a new change is made. So that if it times out, connection lost, refreshed etc the report wont go missing or reset. This is important as the user who's working on it may not be tech savy - once a report is filled and submitted it will be emailed out to admins and anyone associated to the report. It wont be emailed out though in draft state, only whoever is working on it and admins can see it.

Given how extensive some reports may be, it may need to be broken up into like 1,2,3 pages. That once a section like Daily Walk-Through - Critical Systems & Life Safety is done, it moves onto the next section so it isn't like one full long web page that requires scrolling extensivley.

Monthly Closeout & Filing Certification will require work order counts and logging of those daily work orders 

Weekly Report should include a section of the dailys in the end (linked elements) but then have the weekly sprinkler pump logging system tracked first, then at the end it will pull the week long of the dailys. For testing and uploading old documentation, a user can set the dates of the dailys and then the weekly so it adjusts the Sunday->Saturday data pull.
